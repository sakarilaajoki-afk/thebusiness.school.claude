What is inside

A six step method

How to read an extract and answer from it, short enough for students to memorise.

Two extracts with full data

Constructed so every calculation a student attempts agrees with the answer. A full data response set with answers and award guidance, a quantitative skills section and a calculation drill.

Model answers, every sentence tagged

What each sentence earns, including a short model that reaches the same standard in seven sentences, and a mid band answer improved live sentence by sentence.

The errors and the command words

The fourteen errors that cost the most, a command word table, and a one page student guide.

The page most teachers will use first

There is a page on the trap in the first extract. Two figures invite students to compute a price elasticity of demand, and the number they get is arithmetically correct and economically meaningless. What makes the page worth teaching is that the obvious objection is wrong too. A student who spots that supply shifted is thinking correctly, because that is how a demand curve gets identified. The estimate fails for a different reason, and working out which reason is the lesson.

It is editable

The Word file contains both extracts, every question, every answer and every annotation as ordinary text. Swap the market for one your class knows and the method still works, because it describes how to read data rather than which market it is about.
